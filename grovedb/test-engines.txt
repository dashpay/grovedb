# The engines GroveDB's test suite runs on, one a line: its name, then the
# Cargo feature of `grovedb` that compiles the engine.
#
# `cargo test -p grovedb` runs the suite on the first. Another is selected by
# name: `GROVEDB_TEST_ENGINE=pinned-reads cargo test -p grovedb`. CI runs the
# suite once for every line (`.github/workflows/grovedb.yml`). In a build
# without the feature of the selected engine the suite has no engine, and the
# tests that need one are left out.
#
# A name is given its engine type in `src/tests/mod.rs` (`SuiteEngine`).
# `docs/lignindb/test-engines.md` says what registering an engine takes.
rocksdb       rocksdb_storage
pinned-reads  rocksdb_storage
lignin        lignin_storage
